# Manufacturing Workstation Support

## Application launch failure

If a manufacturing workstation application will not start, confirm network connectivity, verify the workstation can reach the approved application endpoint, capture the displayed error, and check whether the issue affects one workstation or multiple stations. Restart the application before restarting the workstation unless the local support procedure requires otherwise.

Do not disable endpoint protection, host firewall controls, or application allowlisting to make the application run. If a security control appears to block the application, collect the event details and escalate to endpoint or security support.

## Shared-floor workstation access

Use named user accounts where supported. Do not share privileged credentials or store passwords in scripts, browser fields, text files, or labels attached to equipment. Password resets and account unlocks must use the approved identity-support process.

## Production floor escalation

For a workstation outage affecting active production, record the asset ID, line or cell, application name, error message, time of failure, and whether an alternate workstation is available. Escalate according to production-impact priority.
